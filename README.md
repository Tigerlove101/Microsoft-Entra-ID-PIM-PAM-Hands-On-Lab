# Microsoft-Entra-ID-PIM-PAM-Hands-On-Lab
This project demonstrates the implementation and testing of Privileged Identity Management (PIM) and Privileged Access Management (PAM) using Microsoft Entra ID in a hybrid identity lab environment.


The objective was to build a controlled privileged-access workflow in which administrative privileges are not permanently assigned to users. Instead, users receive eligible access and activate privileged access only when required.

The lab also demonstrates MFA, password writeback, self-service password reset, role-based access control, just-in-time (JIT) group membership, approval workflows, and PIM auditing.

This project was completed using an on-premises Active Directory environment synchronized with Microsoft Entra ID.
